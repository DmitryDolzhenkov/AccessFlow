Approve/reject/cancel используют общий путь смены статуса (`AccessRequestActionResult`), поэтому BR-15 работает и для cancel против approve. Проигравшее действие отсоединяется от `DbContext`. Текст `409` стал общим: «The Access Request is no longer Pending.» |
